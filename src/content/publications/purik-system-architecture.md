## Scope
PURiK is a modular sensing research platform being developed around Arduino UNO R4 WiFi sensor nodes and an UNO Q ground-station concept. This versioned description documents how device interfaces, driver and adapter boundaries, data transport, processing and human-machine presentation are intended to interact.

## Engineering significance
The design emphasizes testable subsystem boundaries, structured device identity, and interchangeable sensing hardware. Not all features shown in the architecture are physically integrated or verified.
